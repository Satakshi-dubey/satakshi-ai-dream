# Satakshi AI Portfolio

Create a modern, professional, visually striking personal portfolio website for Satakshi Dubey, a second-year B.Tech Information Technology student aspiring to become an AI Engineer. The website should present her as an ambitious technology student who is currently building her programming, AI-tool, prompting, and creative skills.
